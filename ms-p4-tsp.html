01

Project Overview

The Travelling Salesman Problem (TSP) is a classic network optimisation problem: given a set of nodes and distances between them, find the shortest route that visits every node exactly once and returns to the start. It's easy to state but computationally explosive — with 10 cities there are over 3 million possible routes.

The class activity used a delivery network with 5 locations (Warehouse + 4 towns A–D) and real distances. The task: find the optimal route by hand, then find the new optimal when the C–D route is blocked.

03

Evidence from Coursework

Activity
Completed by hand using paper and pencil. First created the network map from the distance table, then enumerated routes systematically. The instruction was explicitly "only use your brain, paper, and pencil."
Solution 1
With all routes open: WH → A → C → D → B → WH = 26 km. This uses the C–D edge (distance 2), which is by far the shortest in the network.
Solution 2
With C–D blocked: must reroute. Best alternative: WH → A → C → B → D → WH = 32 km. Losing the C–D shortcut adds 6 km to the minimum distance.
TSP at scale
With 5 nodes there are 4! = 24 possible routes. With 20 nodes: 19! ≈ 1.2 × 10¹⁷. No computer can enumerate all routes for large TSPs — this is why heuristic algorithms (nearest neighbour, genetic algorithms) exist.
04

What Did I Learn?

Knowledge
Network graph theory basics. The computational complexity of TSP (NP-hard). Why the shortest individual edge (C–D = 2km) disproportionately affects the optimal route. Heuristic vs exact methods.
Skills
Building network maps from distance tables. Systematic route enumeration. Identifying why certain edges are "high-value" to include. Analysing sensitivity (what happens when a route is blocked?).
Reflection
What surprised me: the tiny C–D edge (just 2km) completely dominates the optimal solution. Remove it and the best route jumps by 6km — 23% longer. In real logistics, this is why single road closures or bridge outages can devastate delivery networks. The fragility is built into the topology.
